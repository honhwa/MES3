# 展厅演示包 · 使用说明

**泰州超级电容智能工厂 · 数字化成果演示包（离线版）**
打包日期：2026-10-14　版本：v1.0

---

## 一、这个包是什么

一套**完全离线**的数字化成果演示页面：工厂经营驾驶舱、生产/设备/碳排放数字孪生、批次追溯查询、政府申报版，全部为单文件网页，**零外部依赖**（不联网、不装任何软件、不引外部库）。

## 二、怎么打开

1. 解压 zip（或直接使用本文件夹）；
2. **双击 `showcase.html`**（展厅总控）——推荐入口：左侧场景列表 + 中间演示画面 + 底部旁白，可点「▶ 自动巡演」按导演脚本自动播放；
3. 也可以直接双击任意页面单独演示；
4. 推荐浏览器：Chrome / Edge / 新版 IE 内核浏览器；展厅大屏建议按 **F11** 全屏。

## 四、演示提示

- **数据口径**：全部为确定性模拟演示数据；正式场合如被问及，按导演脚本第一条纪律如实说明。
- **指标口径**：政府申报版每个指标旁有 ⓘ，可现场点开讲解统计口径。
- **样例批次**：追溯页左侧有样例批次快捷按钮（含 2 个不合格样例，可演示质量闭环）。
- **现场互动**：鼓励评审/客户自己输入批次号查询——可验证性是最好的说服。

## 五、口径与免责

- 碳排放口径：速率 =（运行 ? 额定功率×负荷率 : 待机功率）× 电网排放因子（0.5568 kgCO₂e/kWh，2026 年度值）。
- 智能工厂等级定位与 CMMM 能力域为**企业自评演示口径**，正式申报以评价机构发布的评价细则及现场评审结论为准。
- 涉及客户名、供应商名、成本等敏感信息均已脱敏为示例数据。

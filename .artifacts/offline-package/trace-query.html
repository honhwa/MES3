追溯查询

追溯能力说明

正向追溯：成品批次 → 工单 → 8 道工序（设备/人员/时间/关键工艺参数）→ 检验记录 → 物料批次。
反向追溯：点击物料批号 → 该批物料用到的全部成品批次，用于缺陷召回范围界定。
质量闭环：不合格批次的发现 → 隔离 → 处置 → 纠正措施全记录。

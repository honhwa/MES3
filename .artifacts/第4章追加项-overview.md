## 二、关键设计取舍（评审可讲）

### 1. CTP：可交日 = max(排队+换型+生产, 到料+生产)

初学者容易写成「完工或到料取晚」，这是错的——**料到了还要再生产一轮**。所以四段时间线必须摊开：

```
换型（清线15 + 换模具25 + 管路清洗40 + 换辊25 + 换化成工装20）
  → 排队（线体在制工时 ÷ 每日16h）
  → 生产（投产数 = 询单量 ÷ 良率；工时 = 投产数 × 单位工时）
  → 物料（短缺物料最长 L/T + 检验缓冲）
最早可交 = max(排队+换型+生产, 到料 + 生产)
```

**三档承诺而非二元回答**：整单赶不上时算「期望交期前最多能交多少」，≥30% 给「有条件承诺（先交 X 只，余量 Y 日补齐）」，避免一刀切拒绝丢单。每条线给 5 条 `Evidence`，可逐条核对——承诺必须有出处。

### 2. 换型矩阵：时间是算出来的，不是拍脑袋

同型号 = 0；否则 15 + 四维差异（封装 25 / 电解液体系 40 / 极片宽度 25 / 容量段 20）。容量段从型号直接解析（`SC-CX2026-100F` → 100F），其余三维是型号稳定哈希的演示特征（界面注明真实环境取自工艺路线/工装台账）。附「最省换型顺序」（最近邻贪心，对每个起点各走一遍取最优），并与接单顺序对比节省分钟。

### 3. 替代料：认可状态是硬门槛

三道门槛缺一不可：关系成立（用量系数）→ **客户/工艺已认可** → 替代料自己有货。
很多厂栽在第二道：仓库里有料、系统「能顶」，客户没签字，做出去是批量退货。所以「待客户批准」的替代关系**只展示、不参与计算**，并在缺口行明确写出「有关系但待客户批准，不可用」。

### 4. 安全库存补货：ROP = 日均消耗 × 提前期 + 安全库存

含义是「等料这段时间会消耗掉多少 + 安全线」。净库存 = 可用 + 在途 + **草稿**（草稿虽不算在途，但重复下单同样是浪费）；日均消耗与临期看板共用同一口径（领用实测优先 → 工单需求 ÷ 30 天 → 不可估），避免两个页面算出两个数。

## 三、演示路径

**CTP（生产管理 › 交期承诺 CTP）**
1. 型号 `SC-CX2026-100F`、数量 3000、期望交期 +40 天 → 点「⚡ 评估交期」→ **可承诺**，给出承诺日
2. 数量改 20000、期望交期改 +1 天 → **不可承诺**，给出最早可交日与「期望前只能交 0 只」
3. 看线体对比表：L1 在制同型号（换型 0 分钟）、L3 换型 15 分钟、L2 封口机维保不可分配
4. 看瓶颈列：本例瓶颈是**物料齐套**（3 项短缺，最长 L/T 22 天 → 料约 11-11 到）
5. 切「换型矩阵」子页 → 3×3 热力表 → 点「🧮 生成最省换型顺序」看顺序与节省分钟

**物料策略（仓储与出货 › 物料策略）**
1. 「替代料」：型号 100F、数量 6000 → 点「🔍 替代齐套试算」
2. 结果：铝壳缺 1030 → 用加高型顶 800 → **剩 230（部分替代）**；密封圈缺 1030 无替代 → 只能采购
3. 摘要：替代前短缺 2 项 / 2060 → 替代后 2 项 / 1260，1 项已用替代料顶替
4. 上表看「认可状态」：电解液 PC 基是**待客户批准（不可用）**——关系存在但不能用
5. 「安全库存补货」：看 12 种物料的补货点与状态（紧急 3 / 需补货 2 / 正常 4 / 无消耗依据 3）→ 点「⚡ 按建议生成补货申请」→ 到「资材采购申请」提交

## 六、已知限制

- 换型的三个工艺维度（封装/电解液体系/极片宽度）是**演示特征**（型号稳定哈希），真实环境应取自工艺路线、工装台账与换型 SOP；容量段是从型号解析的真实值。
- CTP 的产能口径沿用既有 `GetLineLoad`（在制工时 ÷ 每日 16h），未做班次/节假日/并行工位细化。
- 替代关系为台账手工维护，未做「替代链」（A→B→C）与替代后的质量再验证流程。
- 补货建议按单物料独立计算，未做资金/库位容量约束。
- 单价、L/T、MPQ、临期阈值等仍为演示参数。

## 一、失真定位

| # | 环节 | 具体问题 | 量化 |

| 1 | **列宽换算** | 硬编码 `px = 字符数×7+5`，只对 Calibri 11 成立；原表默认字体是**宋体 11pt**，真实 MDW≈8.2 | A 47→49、B 117→131、**C（点检内容及标准）299→344（差 45px）**、H 159→180 |

## 二、修改点

- `StyledSheetReader`：新增 `ColWidthToPx`（规范公式 `⌊(256w+⌊128/MDW⌋)/256×MDW⌋`）+ `EstimateMaxDigitWidth`（CJK 8.2 / 西文 7，按字号缩放）；未设 ht 的行改读 `sheetFormatPr@defaultRowHeight`

**修完 10 列宽度与参照逐个完全一致**：49/131/344/131/82/164/98/180/82/82

## 三、手写签名

签名列（点检人/确认人）= 隐藏域 + 可点区域；点击弹手写板（canvas，鼠标/触摸均可，DPR 缩放保证清晰），确定后 `toDataURL('image/png')` 写回隐藏 input。

**关键设计**：手写值与普通输入走**完全相同**的 `collect() → values → 归档` 链路，不需要额外存储通道；只读归档把它渲染成 `<img>`，**自包含落盘**（不依赖外部图片），打印、导出、重新打开都正常。

## 本轮（第 5 批）：Excel 尾部汇总行导致 `DataGridViewComboBoxCell 值无效`

### 报错原因
表尾那行 **`本班点检结果汇总（自动统计）｜0 项 OK｜0 项 NG`** 是三块合并单元格（A49:F49 / G49:H49 / I49:J49），非空 3 格 ——
它逃过了"全空行"和"稀疏长文本"两条判据，被当成第 45 条检查项；而 **`0 项 OK` 正好落进「点检结果」下拉列**（候选只有 OK / NG）
→ WinForms 抛 `DataGridViewComboBoxCell 值无效` 并弹系统错误框。

### 两层修复
| 层 | 修法 |
|---|---|
| 解析层 | 表体边界确定后，对**尾部最多 2 行**识别汇总行（非空 ≤3 且首格含 汇总/合计/总计/小计/统计/累计/平均）→ 从表体剥离、归入表尾说明，信息不丢。表2：**45 行 → 44 行**，表尾 2 → 3 条 |
| UI 层（通用） | ① 下拉列赋值前按 `Options` 判定，值不在候选集就**留空让人选**，不再把「0 项 OK」「—」塞进 ComboBoxCell；② `_gridFill` / `_gridTplPreview` 都挂 `DataError`（`e.ThrowException=false` + 状态栏提示一句），任何类型不匹配只提示不弹框 |

### 自查抓到自己引入的 bug
汇总行被**重复收进表尾两次**（剥离后表尾循环仍从原起点扫）。加 `bodyEndRaw` 记录剥离前起点修正 —— 靠"表尾条数"精确断言才抓得到。

- 异常问题追踪表：0 行 → **10 列 × 20 行**，表尾 0 条 ✅
- 表1 / 表2 不受影响（它们先命中"全空行"规则）

| 位置合法性 | sourceRef 解析后必须在表格范围内 | 越界判红 |

### 三色含义
- 🟢 **一致**：模型与规则一致 + 可溯 + 坐标合法 + 置信 ≥60% → 默认勾选
- 🟡 **待确认**：类型不一致 / 置信 <60% / 规则有模型没给（漏项）/ 模型多出原文有的列
- 🔴 **疑似编造**：列名原文找不到 / 坐标越界 → 不采纳、勾选框只读

**点任一行，右侧原文表高亮模型给出的依据格（sourceRef 反查）** —— 这是审厂被追问时的答案。

### 两个安全默认（防"AI 帮倒忙"）
1. **抬头字段默认不替换**：模型只认出 1 项、规则认出 4 项时若自动替换就丢掉 3 项 → 必须人工勾选。
2. **模型多出的列不自动加列**：原文有这个名字判黄（可能规则漏了），原文没这名字判红（编造）。

### 缓存与降级
- `SHA256(文件) + 模型名 + 提示词版本` 作 key，同文件命中缓存**零调用**；可一键清空。
- 非 JSON / 超时 / 未配置 / 整体置信低于 0.35 → 一律 `Ok=false` + 人话原因，**保留规则结果，不抛异常**。
- 置信度门槛取 0.35（低于默认 0.60）的理由：这里产出的是"建议"而非"判定"，后面还有四道校验 + 人工逐项确认兜底，单列低置信只该标黄让人多看一眼，不该整表丢弃。

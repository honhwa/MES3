二、插单模拟：三方案 What-if（方案 2.3）
- 冲突域 = 推荐线在制老工单；三方案：老单延后 / 拆分插空 / 转次优线。

三、缺料三级校验 + 采购前置期 + 自动建单（方案 3.1）
- 一级 需求合并（跨工单按物料累加）→ 二级 扣减（可用 / 在途 / 草稿 / 冻结 / 安全库存）→ 三级 净缺口。
- 采购前置期：需求日 = 最早开工 − 到货缓冲；最晚下单日 = 需求日 −（L/T + 检验缓冲），三色标记逾期/临近/充裕。
- 建议采购量 =（未覆盖缺口 + 安全缺口）× 1.10 → MPQ 向上取整 → 按「需求×1.2 与单次限额取小」钳制。
- 自动建单走既有请购流程（一单一工单、跨工单汇总），并做草稿覆盖去重与数量校验复核，避免多张单重复申请同一批料。

四、物料全链管控：临期三色 + 三方案决策（方案 3.2 / 3.3）
- 三色判定同时看「剩余效期」与「按日均消耗推算的预计用完日」——效期充裕但到期前用不完同样预警。
- 日均消耗双口径：近 90 天已过账领用实测优先；样本不足改用未完工工单 BOM 需求 ÷ 30 天；两者都无标「不可估」不预测。
- 三方案：提前排产消耗 / IQC 重检延期 / 报废处置，逐条给可行性、代价、评分与推荐。
- 分级审批：≤500 元班组长、500~5000 元仓储主管、>5000 元生产经理，级别不够后端直接拒绝且零副作用。
- 兜底：已过期超 15 天未处置只剩「兜底报废」。处置动作复用既有废弃台账与进料检台账，并留决策台账关联单据号。

五、交期承诺 CTP + 换型矩阵（方案 4.1 / 4.2）
- 四段推算：换型 + 排队（线体在制工时）+ 生产（投产数 = 询单量 ÷ 良率）+ 物料（短缺物料最长 L/T）。
- 最早可交日 = max(排队+换型+生产, 到料+生产)——到料后仍需再生产，不等同于「完工与到料取晚」。
- 三档承诺：可承诺 / 有条件承诺（整单赶不上时算期望交期前最多能交多少，≥30% 给部分交付）/ 不可承诺。
- 换型矩阵：型号×型号换型分钟（清线 15 + 封装 25 + 电解液体系 40 + 极片宽度 25 + 容量段 20），附最省换型顺序（最近邻贪心）。

六、物料策略：替代料 + 安全库存补货（方案 4.3 / 4.4）
- 替代料三道门槛：关系成立（用量系数）+ 客户/工艺已认可 + 替代料有库存；待客户批准的关系只展示、不顶缺口。
- 齐套试算按 BOM 行给出 需求 / 主料可用 / 缺口 / 替代可用 / 实替量 / 剩余缺口，并说明不可用原因。
- 安全库存补货：补货点 ROP = 日均消耗 × 采购提前期 + 安全库存；净库存含可用 + 在途 + 草稿；
  建议量按 MPQ 取整、不超单次限额，可一键生成无工单来源的补货草稿（已有未完成申请不重复下单）。

数据口径与设计原则
- 判定权归规则不归模型：所有数字由规则算出，AI 仅做措辞；写入前重算校验。
- 失败零副作用：所有状态流转先整体校验再写入，被拒绝时不产生任何单据或台账。
- 一处口径一处实现：日均消耗、净缺口、补货点均抽公共方法，临期看板与补货页共用，避免两个页面算出两个数。

# SuperCap MES · 超级电容智能工厂制造执行系统

> **EN** — A demonstration MES (Manufacturing Execution System) for a supercapacitor / lithium smart factory: WinForms desktop app + zero-dependency digital-twin web pages + rule-driven AI assistant.

`.NET 10` · `WinForms` · `C#` · `零依赖数字孪生` · `规则驱动的 AI`

---

## ⚠️ 演示原型声明

本项目为**测试 / 演示原型**，用于制造执行系统的功能验证、方案演示与招采/评审场景展示：

- **数据在内存中**，无数据库、无权限体系，**重启后重置为初始演示数据**；
- ERP / 设备 / 计量等外部数据均为**本地模拟**，**唯一真实的外部调用是可选接入的云端大模型（默认关闭）**；
- 全站数字为**自洽的演示口径**，非真实生产 / 经营数据，**不作为财务决算或正式评审依据**。

| **能源与碳**  | 能源台账/查询、碳排放核算、排放因子台账、产品碳足迹、物料碳强度、碳核查、供应链碳、碳资产管理、**峰谷电费"移峰填谷"节约测算**    |

### AI 能力（规则取数 + 模型措辞）

- **AI 助手**：13 类意图，从内存仓储**规则取数**，再由（可选）云端大模型**组织措辞**；回答带**可追溯的数据依据**。
- **铁律**：`判定权归规则，不归模型` —— AI 只"读懂文本、组织语言"，绝不自己取数、不做合格/达标判定、不执行操作；返回数字逐个核对，出现未授权数字即整段丢弃并降级。
- **AI 班报/日报**：一键按本地汇总生成（产量/良率/OEE/异常/工单），云端润色、断网自动降级本地模板。
- **智能排产 AI 推演 / 采购 AI 分析**：规则计算为基准，模型仅补充解释与建议。
- 云端模型走 **OpenAI 兼容接口**（如 DeepSeek），**默认关闭**，API Key 走环境变量、不落库。

### 数字孪生（16 页 · 零外部依赖）

原生 `HTML + Canvas + JS` 自绘，**不引 CDN / WebGL**，可离线双击 / 投屏，也可在 MES3 窗体内经 WebView2 内嵌：

运营大屏 · 经营驾驶舱 · 展厅总控 · 政府申报版 · 生产情况孪生 · 设备孪生 · 碳排放孪生 · **网络孪生（四层拓扑 + 画布独立缩放 + 分层链路 + 机柜下钻 + 告警标红）** · 批次追溯查询 · 质量孪生 · 工艺/配方孪生 · 成本孪生 · 仓储孪生 · 系统集成拓扑 · 过站防呆演示台 · **3D 工厂数据流（等距厂区 + 系统/设备点位 + 应用层数据流 + 网络拓扑叠加）**。

### 贯穿的工程原则

- **判定权归规则，不归模型** —— 可审计、可复现；
- **失败零副作用** —— 过账先整体校验后统一扣减；单据完结先过账后改状态；任何 AI/外部调用失败都安全降级，不写坏数据；
- **绑定与过账解耦** —— 出货绑定不改库存，过账才改库存（两条独立路径）；
- **数据同源、三处一致** —— 业务页 / 报表 / 孪生看板共用同一套仓储汇总口径。

## 🧱 技术栈

- **桌面端**：C# / `.NET 10 (net10.0-windows)` / WinForms，按功能域拆分为多个 `MainForm.*.cs` 分部类。
- **内嵌浏览器**：`Microsoft.Web.WebView2`（可选，反射按需加载，包/运行时缺失时自动降级为外链打开，不崩）。
- **数字孪生页**：原生 HTML/CSS/Canvas/JS，单文件、零依赖、深色主题、自适应缩放。
- **AI**：本地规则引擎 + 可选云端大模型（OpenAI 兼容 `/chat/completions`），结构化调用带容错解析 + 数字白名单核对 + 降级。
- **存储**：内存静态仓储（演示定位）。

## 🚀 快速开始

```bash
# 环境：.NET 10 SDK + Windows（WinForms），建议 Visual Studio 2022/2026
git clone <your-repo-url>
cd MES3

dotnet build SuperCapMES.WinForms/SuperCapMES.WinForms.csproj -c Debug
dotnet run  --project SuperCapMES.WinForms/SuperCapMES.WinForms.csproj -c Debug
```

- 启动后按顶部一级分类 → 二级页签浏览各功能。
- 数字孪生页：进入「数字孪生」分类，点入口卡「新标签页打开」或「内嵌展示」；也可直接双击 `WebAssets/digital-twin/*.html`。
- 云端 AI（可选）：AI 助手页 → 后端设置 → 填写 OpenAI 兼容 BaseUrl / 模型 / API Key（或用环境变量 `DEEPSEEK_API_KEY`）；不配置则全程本地规则引擎，功能不受影响。
